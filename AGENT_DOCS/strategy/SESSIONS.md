# PDJE Strategy Sessions

This file indexes future development strategy meeting logs.

The meeting that created this harness is not recorded as a session file. Its
decisions are captured in `STRATEGY.md` and `MEETING_PROTOCOL.md`.

## Session File Rule

Create future session files under this directory with:

```text
YYYY-MM-DD-short-topic.md
```

Use lowercase words separated by hyphens for `short-topic`.

## Required Session Fields

Each session file should include:

- agenda from the developer
- agent opinion, objections, and alternatives
- accepted decisions
- deferred issues
- whether each deferred issue blocks the current execution
- final plan summary or link
